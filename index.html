Remplissage des tables

La colonne « Table n° » du sheet est prioritaire. Sinon, saisis la table ici (ex. 12 ou 12, 13 pour un grand groupe) — stocké dans l'app, le sheet n'est jamais modifié.

Récap par table — fondues et jambons

Calculé depuis le sheet (colonnes Adultes, -12 ans, Jambons) et le placement. Les enfants de moins de 6 ans gratuits ont leur chaise : ils comptent dans les places mais pas dans les fondues ni les jambons. Les gratuits adultes sont ajoutés en plus (chaise + fondue) — réglable dans Soirée. Les chaises / places en plus demandées dans les remarques (chaise supp, poussette…) comptent dans les places ; corrigeables dans Placement. Pour un groupe réparti sur plusieurs tables, jambons et enfants sont répartis au prorata.

Placeurs

Quand une arrivée est pointée à l'accueil, le nom, le nombre de personnes, la table et le chemin s'affichent sur les téléphones des placeurs. Sur chaque téléphone : ouvrir agencesl68.github.io/fondue-seppois/?placeur, taper le code d'accès puis son prénom. Les messages sont chiffrés : seuls les appareils qui ont le code peuvent les lire.

Lien vers l'ordinateur de l'accueil

Crée un lien privé qui contient le lien du sheet, ton plan de salle, les placements et les chaises en plus. Ouvre-le sur l'ordinateur de l'accueil : tout s'y installe d'un coup (les arrivées pointées ne sont pas transférées). Ne partage ce lien qu'avec l'équipe, comme le lien du sheet.

Sauvegarde

Plan, placements et arrivées sont gardés sur cet ordinateur. Exporte-les pour un autre PC ou en secours.

Code d'accès

Tape le code de l'équipe pour charger les réservations du Google Sheet. Il n'est demandé qu'une fois sur cet ordinateur.
