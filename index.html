Remplissage des tables

La colonne « Table n° » du sheet est prioritaire. Sinon, saisis la table ici (ex. 12 ou 12, 13 pour un grand groupe) — stocké dans l'app, le sheet n'est jamais modifié.

Récap par table — fondues et jambons

Calculé depuis le sheet (colonnes Adultes, -12 ans, Jambons) et le placement. Les enfants de moins de 6 ans gratuits sont indiqués pour info : pas de chaise, pas de fondue ni de jambon. Les gratuits adultes font partie des adultes (comme dans le sheet) — réglable dans Soirée. Les chaises en plus demandées dans les remarques (« chaise supp »…) comptent dans les places ; les poussettes non. Corrigeables dans Placement. Pour un groupe réparti sur plusieurs tables, jambons et enfants sont répartis au prorata. Clique sur une ligne (ou sur une table du plan) pour le détail complet.

Accueil

Téléphones de l'équipe

Chaque placeur ouvre agencesl68.github.io/fondue-seppois sur son téléphone ou sa tablette, tape le code d'accès puis son prénom. Il cherche le nom, valide les arrivées et suit le chemin jusqu'à la table. Les arrivées et le plan se synchronisent tout seuls entre tous les appareils. Les messages sont chiffrés : seuls les appareils qui ont le code peuvent les lire.

Lien vers l'ordinateur de l'accueil

Crée un lien privé qui contient le lien du sheet, ton plan de salle, les placements et les chaises en plus. Ouvre-le sur l'ordinateur de l'accueil : tout s'y installe d'un coup (les arrivées pointées ne sont pas transférées). Ne partage ce lien qu'avec l'équipe, comme le lien du sheet.

Sauvegarde

Plan, placements et arrivées sont gardés sur cet ordinateur. Exporte-les pour un autre PC ou en secours.
